# LUNA APPS

Monorepo for LUNA CODE applications.

## Applications

- `apps/mobile-security` — LUNA MOBILE SECURITY for Android (Kotlin, Jetpack Compose).

## Principles

- Offline-first; security scan results remain on-device.
- No root required; report capability limits explicitly.
- No telemetry or upload of installed-app inventory.
- Remediation always requires explicit user confirmation.
