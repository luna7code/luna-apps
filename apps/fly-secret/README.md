# FLY SECRET application targets

- `web/`: React + TypeScript browser shell.
- `mobile/`: React Native shell for Android and iOS.
- `desktop/`: reserved for the React frontend hosted by Tauri 2 / Rust.

The current foundation contains presentation shells only. It does not implement authentication, messaging, network transport, cryptography, E2EE, or production security claims. Those require their own approved phases and acceptance gates.
